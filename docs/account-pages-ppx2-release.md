# 用户页面与官方价格发布说明

版本：0.2.7-ppx.2。基于现有 0.2.7-ppx.1，不合并新的上游版本。

## 本次范围

- 统一模型价格、公开模型广场、邀请有礼、我的订阅和我的订单的品牌主题。
- 保留充值／购买套餐页面的营销定位，不修改该页面。
- 价格查询显示独立官方目录原价；管理员价格维护单独展示配置价格。
- 原价保留明确零价和图片 Token 单价；缺少目录价格不回退到渠道价。
- 管理订阅在分页前组合筛选，旧订阅只在分组唯一匹配套餐时参与套餐筛选。
- 用户订阅突出额度及有效期，收起技术详情，手动提前使用保留确认。
- 用户订单不提供退款申请入口；管理员退款和实际资金处理规则不变。

## 审查和兼容

此前六项审查问题均有修复及回归覆盖，另修复隐藏当前分组后的失效选择。
价格字段新增源数据存在性元信息，不改实际计费单价或金额计算函数。
没有 Ent schema、Wire 注入或 migration 改动；应用回滚无需数据库降级。
官方价格新字段在旧服务缺失时，前端显示未定价而不冒用折后价格。

本地验证：后端全量 unit / integration、golangci-lint（0 issues）；
前端 3267 项测试、lint、typecheck 和 production build；桌面/手机深浅色浏览器验收。
构建存在既有大 chunk 与 Browserslist 旧数据警告，非本次新增发布阻断项。

## 发布要求

只发布该提交完整 CI 和安全检查通过后生成的不可变镜像。
先稳如狗真实功能验收，再加拿大蓝绿；按用户后续明确要求，不固定等待 30 分钟。
仍需核对健康、计费、Nginx 传输错误、槽位排空、回滚记录和副本状态。
US 不接收应用或秘密；France 只缓存同一镜像，不启动应用或执行迁移。
