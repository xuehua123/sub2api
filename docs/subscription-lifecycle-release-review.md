# 月卡续费展示与自动启用发布说明

版本：0.2.7-ppx.1。基于已合入的上游 v0.2.7，属于 fork 功能发布，不移动现有 v0.2.7 标签。

## 改动

- 管理订阅列表统一查询、排序及分页旧订阅和新权益，避免生效中漏项。
- 用户月卡展示续费、延期和提前启用记录，区分付款成功与权益发放完成。
- 按权益保存自动启用开关，默认关闭。手动保持 90% 门槛，自动要求本期月额度用尽。
- 鉴权只确认后续周期资格；限流与请求校验后准备准入，账号和并发槽就绪后才执行切期。
- 长连接按有效生成帧读取当前设置；查询、取消、配置及纯握手不切期。
- 保留原有有效期扣减、余额兜底和在途请求结算口径，不新增计费账本。

## 迁移与回滚

239_subscription_entitlement_lifecycle.sql 只新增 auto_advance_monthly、last_seen_event_id 和事件表。
历史权益默认不开启自动功能，不修改历史用量或到期时间。迁移后旧版本仍可读写原字段。
回滚应用保留新增字段和记录，不删除用户已经发生的合法延期/切期数据。
每台活动主机启动候选前保存迁移状态、旧镜像及配置，并备份权益相关表。

## 本地审查验证

后端全量单元/集成测试、golangci-lint、前端 lint/typecheck/构建与 3213 个 Vitest 用例已通过。
真实 PostgreSQL 验证并发只切期一次、重复续费幂等、权限隔离及同秒微秒周期标识。
曾复现的禁止模型 HTTP 404 却缩短 20 天问题，修复后验证为 0 次切期、0 秒有效期变化。
浏览器验证桌面及 390px 手机布局、设置保存及历史刷新，无横向溢出。
这些是本地验证；生产必须通过精确提交的 CI、安全检查和不可变镜像版本核对。

## 生产验证要求

先稳如狗后加拿大。稳如狗使用独立测试用户、测试套餐与受控请求做实际 HTTP/UI 验证，
覆盖续费延期、手动提前使用、自动 100% 阈值、日周限制、拒绝模型不切期、并发去重和用户隔离。
真实渠道请求需少量、明确归属测试账号，不修改正常用户权益。结束后停用测试凭据，保留可审计证据。
稳如狗与加拿大分别完成约 30 分钟关键业务观察，运输层错误阻止推广或触发回滚。
美国只验证中继，不部署应用；法国保持副本及应用停止，只缓存候选镜像。
