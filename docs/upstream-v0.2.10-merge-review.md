## 合并决策

1. 保留权益代际、月卡生命周期、余额回退、利润控制、Grok 路由和定价、模型广场官方原价及本地管理页面。
2. 延续 v0.2.5 的架构决策：上游成本监测由 UpstreamConnectionService 统一负责，不恢复旧的逐账号 billing probe 工作器、配置入口或探测倍率调度。历史快照键仅用于升级兼容和失效处理。
3. 合入通用推理强度倍率、媒体计费和新模型价格；未配置的强度按 1 倍，不恢复模型隐式 max 倍率。Free Fast 缺失定价仍保存真实用量和零成本记录。
4. 合入 OpenCode Go 用量刷新及受管字段并发保护。代理身份变化、到期改投和恢复原代理清理旧网络快照；仅改名称不失效快照。续期或回退配置变更通过事务内条件更新避免旧扫描覆盖。
5. 补齐旧调度路径的会话粘性和 previous_response_id 归属路由，同时保留模型、分组、隐私、隔离、原生压缩和利润门检查。自动用卡通知使用冷却限制。
6. 保留断流计费、客户端取消 499 和 SSE 首包统计；桥接 keepalive 不误当业务输出，客户端断开后不重放请求。补齐简易模式 WebSocket 首轮等待后和续轮额度校验。
7. 备份继续仅允许离线恢复。记录写入复用既有 backup:records 锁，备份完成与月归档检查点原子保存，归档保留策略独立处理。保留密钥加密和更换 AccessKey 必须同时提供 Secret 的规则。
8. 设置支持显式 null 清空 OAuth 调度倍率；补齐 Claude 版本自动同步、风控用户白名单和 API 契约。日期范围快捷项跨午夜重新计算。
9. Wire 重新生成；无 Ent schema 变更。上游通用 release.yml 限定在上游仓库运行，fork 仍只使用既有 CI 门禁后的不可变镜像发布流程。
