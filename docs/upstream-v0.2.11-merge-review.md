## 数据库与运行配置

- 本次无新增或修改迁移、Ent schema、依赖或锁文件。加拿大上线前仍需核对其当前版本与 v0.2.10 已引入迁移是否一致。
- API Key 创建限制默认最多 200 个未删除 Key、每小时 60 次；配置为 0 可关闭对应限制。删除 Key 不返还创建次数。

- 不变更生产 Prompt Audit、DNS、数据库角色、财务数据或定价设置。
