# 0.2.7-ppx.4 用户收支报表口径修正

- 消耗直接汇总 usage_logs.actual_cost，保留平台额度。
- 成本直接使用现有账号统计公式：COALESCE(account_stats_cost,total_cost) * COALESCE(account_rate_multiplier,1)，不额外换算。
- 移除用户收支页面的汇率选择、登记接口和相关服务依赖；保留已发布迁移与历史表，不删除数据库内容。
- 保留期间实收减退款减账号成本的利润公式及付款/退款证据不足时的待核对状态。
- 修正外部收银台的 redeem_type 分类兼容，不再将月卡记录默认归为余额；不扩展旧收银台功能。
- Wire 生成文件同步，增加原始成本、零成本、跨日一致性、无汇率参数回归测试。

## 验证

本地修正版SQL在加拿大生产数据的只读、REPEATABLE READ事务中验证：昨日、近7天、近30天共372项独立对账通过。只输出匿名汇总及用户ID，不改变账目或生产应用。

## 发布

依用户明确指示，本次跳过稳如狗，仅加拿大蓝绿发布。CI通过后使用精确提交的不可变摘要镜像，记录旧槽回滚，验证迁移不变、新版接口原始成本一致、健康及中转路径。法国仅缓存镜像，应用保持停止；美国不部署。不修改DNS、支付、余额或汇率数据。
