工具接入

Cherry Studio

选择适合当前网络的端点，按下面的步骤完成接入。

第三方工具：确认 UA 被保留

使用客户端或中间代理对接时，确认实际发出的请求带有 User-Agent。工具已正常发送自身 UA 时保留它；支持自定义 Headers 的工具可补充真实应用标识。不要假定 CCSwitch 本身的配置会替所有工具发出 UA，也不要用 UA 冒充其他工具。

  1. 打开“设置” → “模型服务”，新增 OpenAI 服务商。
  2. API 地址填写 https://api.psydo.top/v1。
  3. 粘贴您在皮皮虾 AI 控制台创建的 API Key。
  4. 点击获取模型或手动添加控制台可见的模型名称。
