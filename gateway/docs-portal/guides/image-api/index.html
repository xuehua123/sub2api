API 与开发

图片生成 API

选择适合当前网络的端点，按下面的步骤完成接入。

API 对接必查：请求 Header 带上 User-Agent（UA）

自建 API 请求请显式设置 User-Agent: pipixia-client/1.0，也可以替换为您真实的应用名称与版本，例如 my-app/1.0。字段名是 User-Agent，不是 UA；它放在请求头里，不是 JSON 请求体。不要填密钥或个人信息。

推荐给 Codex 用户的生图方式：CCSwitch 继续使用普通编程分组 Key运行 Codex；另外新建一把绑定生图 API 分组的 Key，只让项目里的生图 Skill 读取和调用。

  1. 在控制台“API 密钥”新建一把 Key，分组选择生图 API 分组。不要把正在给 CCSwitch 使用的编程 Key 改到生图分组。
  2. 在需要生图的项目根目录创建 .pipixia-image/config.json，填入生图 Key、地址和图片模型。
  3. 将 .pipixia-image/config.json 加入该项目 .gitignore，确保绝不提交到 Git。
  4. 把下方“给 Codex 的提示词”发到该项目的 Codex 对话中。完成后，以后直接说“调用皮皮虾生图 Skill 生成一张……”即可。
.pipixia-image/config.json
{
  "base_url": "https://api.psydo.top/v1",
  "api_key": "在这里粘贴生图 API 分组 Key",
  "model": "在控制台模型列表确认的图片模型名称"
}
.gitignore
.pipixia-image/config.json
给 Codex 的提示词
请在当前项目创建一个本地生图 Skill。只读取项目根目录 .pipixia-image/config.json 中的 base_url、api_key、model，通过 POST {base_url}/images/generations 调用皮皮虾 AI 生图，请求头必须包含 User-Agent: pipixia-client/1.0。

创建 .codex/skills/pipixia-image/SKILL.md 和可重复调用的本地脚本：支持 data[].url 与 data[].b64_json 响应，将图片保存到 output/images/。确保 .pipixia-image/config.json 已加入 .gitignore。严禁把 API Key 写进源码、日志、命令输出、Git 或生成文件；成功后只汇报图片文件路径、模型和必要错误信息。先检查当前项目技术栈，沿用已有脚本约定。

只有在您自己写脚本或接入第三方生图客户端时，才直接使用下面的 HTTP 示例。该示例中的 $PIPIXIA_IMAGE_API_KEY 必须是生图 API 分组的 Key。

cURL
curl "https://api.psydo.top/v1/images/generations" \
  -H "User-Agent: pipixia-client/1.0" \
  -H "Authorization: Bearer $PIPIXIA_IMAGE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"图片模型名称","prompt":"一幅夜晚海边的水彩画","size":"1024x1024"}'
继续在皮皮虾控制台操作
