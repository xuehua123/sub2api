API 与开发

Node.js / TypeScript

选择适合当前网络的端点，按下面的步骤完成接入。

API 对接必查：请求 Header 带上 User-Agent（UA）

自建 API 请求请显式设置 User-Agent: pipixia-client/1.0，也可以替换为您真实的应用名称与版本，例如 my-app/1.0。字段名是 User-Agent，不是 UA；它放在请求头里，不是 JSON 请求体。不要填密钥或个人信息。

设置本机环境变量 PIPIXIA_API_KEY 和 PIPIXIA_MODEL 后，运行下面的示例。

1. 安装 SDK

终端
pnpm add openai

2. 配置环境并发送请求

PowerShell · 设置当前会话
$env:PIPIXIA_API_KEY = [System.Net.NetworkCredential]::new("", (Read-Host "API Key" -AsSecureString)).Password
$env:PIPIXIA_MODEL = Read-Host "模型名称（从当前 Key 的列表复制）"
JavaScript / TypeScript
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.PIPIXIA_API_KEY,
  baseURL: "https://api.psydo.top/v1",
  defaultHeaders: { "User-Agent": "pipixia-client/1.0" },
});
if (!process.env.PIPIXIA_MODEL) throw new Error("请设置 PIPIXIA_MODEL");
const result = await client.chat.completions.create({
  model: process.env.PIPIXIA_MODEL,
  messages: [{ role: "user", content: "你好" }],
});
console.log(result.choices[0]?.message.content);

3. 验证

预期输出模型回复。在控制台调用记录中确认模型、用量和扣费来源。
