API 与开发

Python SDK

选择适合当前网络的端点，按下面的步骤完成接入。

API 对接必查：请求 Header 带上 User-Agent（UA）

自建 API 请求请显式设置 User-Agent: pipixia-client/1.0，也可以替换为您真实的应用名称与版本，例如 my-app/1.0。字段名是 User-Agent，不是 UA；它放在请求头里，不是 JSON 请求体。不要填密钥或个人信息。

先在本机设置 PIPIXIA_API_KEY 和 PIPIXIA_MODEL。模型名称从当前 Key 的模型列表选择。

1. 安装 SDK

终端
pip install openai

2. 配置环境并发送请求

PowerShell · 设置当前会话
$env:PIPIXIA_API_KEY = [System.Net.NetworkCredential]::new("", (Read-Host "API Key" -AsSecureString)).Password
$env:PIPIXIA_MODEL = Read-Host "模型名称（从当前 Key 的列表复制）"
Python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["PIPIXIA_API_KEY"],
    base_url="https://api.psydo.top/v1",
    default_headers={"User-Agent": "pipixia-client/1.0"},
)
reply = client.chat.completions.create(
    model=os.environ["PIPIXIA_MODEL"],
    messages=[{"role": "user", "content": "你好"}],
)
print(reply.choices[0].message.content)

3. 验证

运行脚本后应输出模型回复。若环境变量缺失，先设置再运行；若模型不支持 Chat Completions，请改用对应协议的示例。
