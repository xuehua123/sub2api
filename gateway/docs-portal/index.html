API 对接必查：请求 Header 带上 User-Agent（UA）

自建 API 请求请显式设置 User-Agent: pipixia-client/1.0，也可以替换为您真实的应用名称与版本，例如 my-app/1.0。字段名是 User-Agent，不是 UA；它放在请求头里，不是 JSON 请求体。不要填密钥或个人信息。

接入前，准备三样东西

  1. 一个可用的账户

    在控制台确认余额或有效套餐，以及套餐支持的分组。

    查看套餐 →
  2. 一把对应分组的 Key

    创建 Key 时确认分组、消费来源和独立限额。不要把不同工具的设置混在一起。

    创建 API Key →
  3. 一个当前可用的模型

    模型名从该 Key 的模型列表选择；公开模型广场不等于每把 Key 都能调用。

    查询模型 →

先验证，再接入复杂任务

PowerShell · 查询模型
$env:PIPIXIA_API_KEY = [System.Net.NetworkCredential]::new("", (Read-Host "API Key" -AsSecureString)).Password
Invoke-RestMethod -Uri "https://api.psydo.top/v1/models" `
  -Headers @{ Authorization = "Bearer $env:PIPIXIA_API_KEY"; "User-Agent" = "pipixia-client/1.0" }

预期结果是模型列表。确认连接与权限后，再打开上面的工具教程发送一条简单请求。

地址不要重复拼接

OpenAI 兼容 Base URL 通常以 /v1 结尾；Claude Code 的 ANTHROPIC_BASE_URL 使用根地址。每篇教程给出的字段值已经包含所需路径。
