排查与支持

提交排查信息

一次给出关键线索，减少来回确认。

先准备这五项

  1. 正在使用的 URL

    复制客户端实际配置的地址，不只提供站点名称。

  2. Clash 代理节点及日志截图

    说明是否开启代理、是否命中正确线路；截图遮住订阅地址、密钥等内容。

  3. 所选分组

    同时给出实际模型名称，便于检查匹配关系。

  4. 渠道状态

    普通用户提供公开服务状态与检测时间；管理员可补充渠道管理中的状态及对话延迟。

  5. 额度卡类型和余额状态

    提供到期时间、剩余额度、Key 消费来源与独立限额情况。
